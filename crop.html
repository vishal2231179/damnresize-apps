Why use DamnResize Image Cropper?

Cropping removes unwanted edges and keeps only the part of a photo that matters. This free image cropper works with JPG, PNG and WebP images directly in your browser. You choose the crop position and size in pixels, and your image is processed on your device without being uploaded by this page. The cropped image is downloaded as a JPEG file, so please preview it before using it.

How to crop an image online

  1. Click "Select Image File" and choose a JPG, PNG or WebP image.
  2. Set Crop X and Crop Y. These are the distance in pixels from the left and top edges where the crop starts.
  3. Set Crop Width and Crop Height to the size of the area you want to keep.
  4. Click "Crop Image" and check the preview.
  5. Click "Download Cropped Image" to save the file.

After cropping

Cropped images often still need the right dimensions or file size. Use the Image Resizer to set exact width and height, or the Image Compressor to reduce the file size in KB. For application forms, try the Govt Exam Photo & Signature tool and read the SSC photo and signature guide.

Frequently asked questions

Is this image cropper free?

Yes. It is free to use, with no signup and no watermark.

Is my image uploaded to a server?

No. This page crops the image in your browser using the canvas API, so your file stays on your device.

What do Crop X and Crop Y mean?

Crop X is how many pixels from the left edge the crop begins, and Crop Y is how many pixels from the top edge. Crop Width and Crop Height set the size of the area you keep.

Which image formats are supported?

You can upload JPG, PNG and WebP images. The cropped image is downloaded as a JPEG file.

Does cropping reduce image quality?

Cropping keeps the original pixels of the selected area, but the JPEG download is compressed slightly. Preview the result before you use it.
