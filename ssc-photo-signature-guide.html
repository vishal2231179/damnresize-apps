Application photo guide

How to Resize an SSC Photo and Signature for an Online Form

A photo can look fine on your phone and still fail an application upload because its dimensions, file size, format, or crop do not match the current instructions. Use this checklist to prepare the files and check them before submitting.

Published and reviewed: October 20, 2026 · About a 4-minute read

Important: SSC requirements can vary by examination and notification. This independent guide is not an SSC instruction or a guarantee that an image will be accepted. Always follow the current notice and the live application form.

Before you start: check the active notice

Open the official Staff Selection Commission website and find the notice and application instructions for the examination you are applying to. Check the photo and signature requirements separately; they may have different dimensions, file-size limits, formats, or other conditions.

Write down the exact permitted width and height (or proportions), minimum and maximum file size, and accepted file type. If the notice gives a live upload preview or additional photo rules, follow those too. Do not rely on an old tutorial or assume every SSC application uses the same settings.

Prepare the photo and signature

  1. Start with a clear original. Use a well-lit, in-focus photo that follows the notice's background, framing, and appearance rules. Use a clear signature on a plain background. Keep the original files so you can try again if needed.
  2. Use separate files. The application normally asks for the photograph and signature in separate upload fields. Prepare and check each one independently.
  3. Choose the right crop. Resizing changes pixel dimensions; it does not make an unsuitable photo or signature compliant. Check that the face is not cut off and that the full signature remains visible.
  4. Match the file-size range. Being below a maximum is not enough if the notice also sets a minimum. Check the final downloaded file is inside the full permitted range.

Use the DamnResize exam photo tool

  1. Open the Exam Photo & Signature tool and select SSC from the examination menu.
  2. Upload the photo in the photo box. Check the preview, then use Process & Download Photo.
  3. Upload the signature separately in the signature box and use Process & Download Signature.
  4. Open both downloaded files. Verify the visible crop, dimensions, format, and file size against the active notice before uploading them to the official form.

The tool applies its available preset and compresses toward a file-size ceiling; it does not verify every rule in the current SSC notice or guarantee that the result meets a required minimum size. If the preset does not match your notice, or the crop/size is unsuitable, do not submit that output as-is. Use the image cropper or image resizer to adjust it, then check the final file again.

Why can an upload be rejected?

  • The file is outside the allowed size range or uses an unsupported format.
  • The pixel dimensions or proportions do not match the current application instructions.
  • The photo is blurry, poorly lit, framed incorrectly, or cropped so the face is cut off.
  • The signature is faint, incomplete, difficult to read, or has too much blank space.
  • The wrong file was selected, or the upload did not finish successfully.

If the form still rejects an image, read its exact error message, compare the file properties with the notice, and create a new copy from the original. Avoid repeatedly uploading the same file without checking what failed.

Final checklist before submitting

  • I checked the current notice for this specific examination.
  • The photograph and signature are separate, clear, and correctly framed.
  • Each file's dimensions, format, and size meet the stated limits, including any minimum.
  • I opened the final downloaded files and checked that nothing important was cropped out.
  • I reviewed the preview and upload confirmation on the official application form.

Frequently asked questions

Can I use one photo size for every SSC exam?

Do not assume so. Check the current notice and upload instructions for the specific examination and application cycle.

Is reducing the file size enough?

No. The format, pixel dimensions, complete size range, image quality, crop, and any other stated conditions also matter.

Will using a resize tool guarantee acceptance?

No. A tool can help change an image, but only the official application instructions determine what is acceptable.
